# 営業管理ダッシュボード UI/UX 再設計プロンプト

> このまま AI 設計ツール（Claude / ChatGPT / v0 / Figma AI 等）に貼り付けて使うプロンプトです。

---

## 1. プロジェクト概要

営業代行会社で「プレイヤー兼マネージャー」として2名の営業チーム（自分＋部下）を運営しているオーナー向けの、**自社用営業管理ダッシュボード**です。
ローカルホスト（macOS、Streamlit）で動作し、本人と部下の双方が使います。

**目的:**

1. 数字管理上の **記入漏れ** を機械的に検出して通知（カレンダー × ヨミ表突合）
2. **停滞案件** を可視化
3. **目標 vs 実績** の進捗を一目で把握
4. メンバー別 / チーム全体 の比較

**コア価値:**

> 「シートを開かなくても、ダッシュボードと LINE 通知だけで状況が分かる」

| I | 初回実施済 |

| T | 2回目実施済 |
| U | 2回目見込み |
| W | 現況ステータス（検討中 / 長期追客 / 2回目商談日程確定 / 2回目商談日程調整中 / 失注 / SP / リスケ / 契約済） |

## 3. ダッシュボードに必要な機能（タブ構成）

### Tab 1: ⚠️ 警告

**3.1 記入漏れアラート**

カレンダー予定（`様` 含む）vs ヨミ表の活動ログを突合して、ヨミ表に記入されていない予定を一覧表示。

- 対象期間: 過去1週間（デフォルト）
- 表示項目: 担当 / 日付 / 予定タイトル / 推定顧客名

**3.2 停滞案件アラート**

最終活動日（初回/2回目/契約のうち最大）から **7日以上** 動きがなく、かつ現況ステータスがホワイトリスト（検討中 / 長期追客 / 2回目商談日程確定 / 2回目商談日程調整中）に該当する案件。

- 表示項目: 担当 / 顧客名 / 現況ステータス / 進捗 / 見込み / 最終活動日
- **インライン操作**: 各案件の現況ステータスをドロップダウンで変更し、Google スプレッドシートの W 列に書き戻す

### Tab 2: 📈 進捗推移（**最優先で再設計したい**）

対象セレクタ: `松戸 / 鈴木 / チーム全体`

#### 表示すべき KPI（目標と実績、達成率）

**件数系:**
- アポ数（初回アポ日が期間内）
- 着座数（初回アポ実施＝商談数）
- 2回目アポ設定数（2回目商談日が期間内）
- 2回目アポ実施数
- 契約数（契約実施日が期間内）
- 成約数（成約日が期間内）

**金額系:**
- 契約額
- 成約額

#### 期間粒度

- **月全体**（1日〜末日）
- **週別**（1週目=1〜7日 / 2週目=8〜14日 / 3週目=15〜21日 / 4週目=22〜末日）
- **日次**（当月の各日）

#### 推移の見せ方

- 累積実績 vs 累積目標（理想ペース）の "Pace to Goal" 線
- 各週の実績バー + 目標線
- 達成率の色分け（緑 ≥ 100% / 青 70-99% / 黄 40-69% / 赤 < 40%）

### Tab 3: 👤 個人

メンバー別のファネル（リード → 初回予定 → 初回実施 → 2回目予定 → 2回目実施 → 契約）と見込み別件数。

### Tab 4: 👥 チーム

チーム合計のファネルと見込み別件数。

## 4. デザイン要件

### 4.1 参考にしたいデザイン

**Salesforce Sales Cloud / Lightning Experience** の Operational Dashboard 風:

- ヒーロー KPI カード（上部に大きな数字 + 達成率 + 目標値）
- 横向きの Goal Progress バー（実績の塗り + 目標位置のマーカー線）
- コンバージョンファネル（横棒で各ステージを表示、ステージ間の変換率を併記）
- Pace to Goal（累積推移グラフ：理想線と実績線）
- 落ち着いた配色（Salesforce ブルー #0070d2 / グレー #5e6a72 / 成功グリーン #2e844a / 警告イエロー #ffb75d / 危険レッド #ea001e）
- 角丸 4-8px、白基調、ドロップシャドウは浅め

### 4.2 ユーザーが感じている現状の課題

> 「グラフがわかりづらい。文字とバーが被って数字が読めない。情報量が多すぎて、何を見ればいいか分からない」

→ **情報を絞り、各セクションで "今何が起きているか" がぱっと分かるレイアウト** にしてほしい。

### 4.3 推奨フロー（重要）

ダッシュボード初見の人が **5秒で読める** 順序:

1. **今月の進捗は順調か？**（達成率の色 + 目標までの距離）
2. **どこで詰まっているか？**（ファネルでボトルネック特定）
3. **今週は目標ペースに乗っているか？**（Pace to Goal）
4. **今すぐアクションが必要なものは？**（記入漏れ / 停滞）

## 7. 制約・お願い

- **情報過多にしない**。1セクション = 1つの問いに答える。
- **目標 vs 実績の対比は必ず視覚的に** 表現する（数字だけ並べない）。
- **配色は意味を持たせる**（緑=達成、青=順調、黄=注意、赤=未達）。
- **モバイル対応は不要**（PC ブラウザで見ることが前提）。
- **デバッグ用の冗長な数字表示は不要**。
