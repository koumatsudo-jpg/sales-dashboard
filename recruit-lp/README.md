# 内定率診断LP(インターン候補リード獲得用)

「あなたの志望企業、内定率は何%?」— 学生向けの診断コンテンツで、
長期インターン候補のリード(氏名・大学・卒業年・メール等)を獲得するためのランディングページです。

## 仕組み

```
学生が診断に回答(10問・約30秒)
   ↓
結果表示の直前にリード情報を入力(名前・大学・卒業年・メール ほか)
   ↓
① Google Apps Script 経由でスプレッドシートに自動蓄積(回答内容・スコア込み)
② その場で診断結果+改善アドバイス+長期インターンCTAを表示
```

- **完全静的サイト**(HTML 1ファイル)。GitHub Pages や Netlify で無料公開可能
- リードには **全回答・診断スコア・弱点TOP3** が付くので、営業時のトークに使えます
- スパム対策(ハニーポット)、送信失敗時のローカル退避、X シェアボタン付き

## セットアップ

### 1. リード保存先(Google スプレッドシート + Apps Script)

1. リード蓄積用の Google スプレッドシートを新規作成
2. メニュー「拡張機能 → Apps Script」を開く
3. `gas/lead-collector.gs` の内容を貼り付けて保存
   - 新規リードのメール通知が欲しい場合は `NOTIFY_EMAIL` に自分のアドレスを設定
4. 「デプロイ → 新しいデプロイ → 種類: ウェブアプリ」
   - **実行するユーザー: 自分** / **アクセスできるユーザー: 全員**
5. 発行された `https://script.google.com/macros/s/.../exec` のURLをコピー

### 2. `index.html` の CONFIG を編集

`index.html` 内の `CONFIG` を書き換えます:

```js
const CONFIG = {
  GAS_ENDPOINT: "https://script.google.com/macros/s/XXXX/exec", // 手順1のURL
  CTA_URL: "https://...",       // 結果画面のボタン遷移先(インターン応募フォーム・LINE登録など)
  COMPANY_NAME: "株式会社〇〇",  // 運営会社名(フッター・プライバシー表記)
  PRIVACY_CONTACT: "info@your-domain.jp", // 個人情報の問い合わせ窓口
};
```

### 3. 公開(GitHub Pages の場合)

1. GitHub リポジトリの Settings → Pages
2. Source: 「Deploy from a branch」、Branch: `main` / フォルダ `/ (root)` を選択
3. 公開URLは `https://<user>.github.io/<repo>/recruit-lp/` になります

> 独自ドメインやサブディレクトリ非表示にしたい場合は、`recruit-lp/` の中身だけを
> 別リポジトリ(または Netlify / Cloudflare Pages)に置いてもそのまま動きます。

### 4. 動作確認

1. 公開URLをスマホで開き、診断→フォーム送信まで通す
2. スプレッドシートの「リード一覧」タブに行が追加されることを確認
3. `GAS_ENDPOINT` 未設定のまま公開しないこと(リードが保存されません。
   未設定時はブラウザのコンソールに警告が出ます)

## 集客の流し込み先(例)

- 大学の就活系 X / Instagram アカウント・広告
- 就活コミュニティ・オープンチャットでのシェア(結果のXシェアボタンで二次拡散)
- QRコード化して学内イベント・チラシに掲載

## カスタマイズ

| 変えたいもの | 場所 |
|---|---|
| 質問・選択肢・配点 | `index.html` の `QUESTIONS` 配列(`score: 0〜3`、業界/企業レベルは `coef`) |
| 判定コメント(A〜D) | `TIERS` 配列 |
| 弱点別アドバイス文 | `ADVICE` オブジェクト |
| スコア計算式 | `computeScore()`(準備度×業界係数×企業レベル係数、5〜92%にクランプ) |
| 配色 | `<style>` 冒頭の CSS 変数(`--brand` など) |

## 法務・運用上の注意(必ず読んでください)

- 診断結果は**シミュレーション(目安)であり実際の内定確率ではない**旨を、
  スタート画面と結果画面の2箇所に明記しています。**この文言は消さないでください**
  (優良誤認と受け取られるリスクを避けるため)。
- 個人情報の利用目的(診断結果の提供・インターン等の案内)への
  **同意チェックを必須**にしています。取得した情報は表記した目的の範囲で利用し、
  案内メールには配信停止手段を必ず付けてください。
- フッターのプライバシー表記は最低限の雛形です。公開前に自社のプライバシーポリシー
  ページがあればそちらへリンクを差し替えることを推奨します。
